# PDF Studio Local — shell desktop

Ce workspace contient uniquement l’intégration native Tauri v2. Le frontend reste
dans `apps/web` et le moteur PDF dans `services/pdf-engine`; ce découpage évite de
coupler leur mode web/dev au packaging natif.

Voir [`../../DESKTOP.md`](../../DESKTOP.md) pour les prérequis, commandes,
permissions et limites de DESKTOP-001.
