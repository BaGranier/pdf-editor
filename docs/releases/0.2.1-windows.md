# PDF Studio Local 0.2.1 pour Windows x64

**Candidate locale · VM de développement · Diffusion non qualifiée**

Save et Save As Desktop lisent les octets de la réponse du moteur avant de
construire le Blob PDF dans WebView2. Sept copies ont été écrites et relues sur
le NSIS installé. La limite Preview de 25 Mio par PDF généré reste applicable.
Le dialogue de destination et l'écriture atomique restent natifs.

Une nouvelle ouverture PDF, y compris par une seconde invocation Windows,
est transmise à l'instance active et réactive l'onglet si le document source
est déjà ouvert. La mise à niveau silencieuse depuis la candidate historique
0.2.0 conserve la préférence de thème observée.

Le paquet demeure non signé. L'OCR embarqué anglais et français a été
vérifié avec le réseau hôte disponible. La VM propre et le bootstrap WebView2
sans runtime restent à qualifier. Pour imprimer, exporter la composition puis
passer par un lecteur externe. L'impression intégrée reste expérimentale.
