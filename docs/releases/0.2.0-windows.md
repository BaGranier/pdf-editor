# PDF Studio Local 0.2.0 pour Windows x64

## Binaire reconstruit WIN-FINAL-020

**Windows x64 · VM de développement testée · NOT QUALIFIED / NOT FOR DISTRIBUTION**

Le NSIS 0.2.0 a été recompilé depuis `59fe91e8648827091f05ded468301a1ce3650d4b`.
Il conserve la lecture des réponses PDF WebView2 avec `arrayBuffer()` et la gestion
native des ouvertures en instance unique. Les popovers, styles et le rendu à faible
zoom issus de DESKTOP-005 restent partiellement reportés. Les candidats historiques
[0.2.0 de WIN-RELEASE-002](#candidate-historique-win-release-002) et [0.2.1 de WIN-RELEASE-003](0.2.1-windows.md)
conservent leurs propres rapports et SHA-256.

Save et Save As préservent la source et appliquent le plafond Preview de 25 Mio
au PDF généré. Les deux gros PDF historiques sous ce seuil ont été écrits et
relus. Pour imprimer, exporter la composition, ouvrir le PDF dans un lecteur
externe et lancer l’impression depuis ce lecteur. `PRINT-01` reste ouvert.

Le sidecar Python et les langues OCR anglaise et française sont embarqués.
L’identifiant Tauri reste `com.local.pdfstudio`. Le NSIS est non signé. WebView2
est requis et l’installateur prévoit un bootstrap réseau si le runtime manque.
La VM vierge et le bootstrap n’ont pas été qualifiés. Aucun test de migration
des préférences entre deux versions n’est revendiqué pour cette campagne.

## Candidate historique WIN-RELEASE-002

**Candidate de diagnostic · NOT QUALIFIED / NOT FOR DISTRIBUTION**

Depuis le tag 0.1.0, le dépôt intégré ajoute l'ouverture et la composition
d'images, les liens et signets PDF, les modes multipages, les thèmes et les
sept catégories SVG. Il ajoute aussi les tampons, les filigranes répétés,
le biffage par zones et les sessions temporaires pour PDF protégés.

La campagne 0.2.0 corrige les demandes d'extraction redondantes pendant le
montage d'une page et la lecture du témoin de filigrane sous Windows. Save
conserve la source et applique un plafond Preview de 25 Mio par PDF généré.
Sur la candidate, Save As de gros PDF peut échouer dans WebView2 avant le
dialogue, y compris sous la limite.
Sur la VM de développement, le NSIS x64 non signé lance le sidecar local avec
Python et les langues OCR intégrés. Avec WebView2 absent, l'installateur utilise
le bootstrapper réseau. Tauri conserve l'identifiant `com.local.pdfstudio`.

L'impression intégrée reste expérimentale. En Preview, exporter la composition
et l'imprimer depuis un lecteur externe. OCR et conversion travaillent sur la
source de l'onglet. Exporter et rouvrir la composition pour traiter les
modifications. L'historique des objets reste distinct de l'organisation des
pages. La reconstruction DOCX conserve ses limites de fidélité.

L'identité du paquet, les résultats installés et les scénarios encore ouverts
figurent dans le [rapport WIN-RELEASE-002](../qa/runs/2026-11-23-windows-release-qualification.md).
